# Финансовый помощник — Telegram-бот

Личный учёт денег семьи в Telegram:

- ручной ввод одной строкой: `500 продукты`, `1.5к такси`, `+80000 зп`;
- импорт выписок: PDF «Справка о движении средств» Т-Банка и CSV-выгрузка ВТБ Онлайн
  (итоги сверяются со справкой банка, повторная загрузка не создаёт дублей);
- переводы между своими картами находятся автоматически и не считаются доходом/расходом;
- автокатегории + свои правила (`/rule 5722835740 = Жена`);
- отчёты за период, по месяцам, «стоимость кредитов» (комиссии, проценты, страховки), выгрузка в CSV.

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и свой ALLOWED_USER_IDS
python main.py
```

Данные хранятся в SQLite (`data/finance.db`). Выписки и база в git не попадают (`.gitignore`).

## Команды

`/help` — справка, `/report [период]`, `/months`, `/export`, `/accounts`, `/rename`,
`/rule`, `/rules`, `/delrule`, `/find`, `/cat`, `/undo`, `/wipe`.

Периоды: `месяц`, `прошлый`, `неделя`, `год`, `2026-10`, `10.2026`, `октябрь`, `всё`.
