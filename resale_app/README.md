# Перекуп 1000 — приложение для iPhone

Помощник для перепродажи товаров из Китая в России со стартовым бюджетом 1000 ₽.

- **Анализ** — рейтинг 11 товаров: цена закупки, цена продажи, наценка, риск, конкуренция, где купить и где продать.
- **План** — готовое распределение 1000 ₽ и прогноз роста при реинвестировании.
- **Расчёт** — калькулятор прибыли для любого товара и канала продаж (Авито, VK/Telegram, WB, Ozon).
- **Учёт** — журнал закупок и продаж (хранится на телефоне).
- **Гайд** — площадки, запреты, налоги (самозанятость), защита от мошенников.

## Как поставить на iPhone

1. Опубликуйте папку `resale_app` на любом HTTPS-хостинге, например GitHub Pages
   (Settings → Pages → ветка, затем откройте `https://<логин>.github.io/telebot/resale_app/`).
2. Откройте ссылку в **Safari** → «Поделиться» → **«На экран „Домой“»**.
3. Приложение появится с иконкой и работает без интернета.

## Разработка

Правьте `app.html`, затем соберите `index.html`:

```
python3 build.py
```

Цены в приложении — оценки (ноябрь 2026). Перед закупкой проверяйте актуальные цены на Авито в своём городе.
